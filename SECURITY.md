# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or vulnerability in Stellar Threads Core or contract interfaces, please report it privately:
- Email `security@stellar-threads.org` or submit via GitHub Private Vulnerability Reporting.
- Include reproduction steps and technical details.
- Do not disclose issues publicly until resolved.
